# Datasets and corpora

We expect several qualitatively different corpora.

## 1. Truth corpus

Produced from native-game/parity instrumentation, primarily maintained by `sts2-emulator`.

Conceptually:

```text
(S, action, S_native')
```

Used to verify mechanics. It is not a strategic training target by itself.

## 2. Search corpus

Expensive counterfactual analysis generated by `sts2-ai`:

```text
root state / observation
legal actions
search statistics
child outcomes
value estimates
policy targets
provenance
```

This is the persistent strategic evidence layer.

## 3. Training corpus

Compact examples distilled from search evidence, for example:

```text
(observation, pi_search, V_search)
```

or other supervised/RL targets.

## 4. Scenario archive

Strategically important states deliberately retained for repeated study:

- policy/search disagreement;
- high model uncertainty;
- rare relic/card interactions;
- close shop/path/card decisions;
- low-HP survival situations;
- unusual decks;
- boss relic choices;
- historically misplayed states.

The first prototype archive is **replay-first** rather than snapshot-first. A scenario records:

```text
run seed
stable action-ID prefix
decision index
exact state hash
emulator revision
information policy
root action values / visits / uncertainty
reason / tags
```

Loading a scenario resets the emulator, replays the stable action prefix, and refuses the result if
the emulator revision or exact state hash differs. This avoids inventing a state-deserialization ABI
before we need one.

Current mining prioritizes small best-vs-second value margins, then larger reported uncertainty.
The scenario archive prevents repeated analysis from spending nearly all compute rediscovering
ordinary early-run positions.

## Storage policy

Large data does not belong in Git. Git stores:

- schema definitions;
- small fixtures;
- dataset manifests;
- checksums;
- generation configuration;
- provenance.

Actual corpora should live in local/object/distributed storage selected later.

A manifest should record at least:

```text
dataset_id
created_at
ai_commit
emulator_commit
game_build
information_policy
generator/search/model versions
record count
content checksum/storage URI
```
