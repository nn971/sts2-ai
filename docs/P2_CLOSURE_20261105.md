## Final P2.5 acceptance protocol (fish, local 15-worker CUDA)

Use the **trained** round-2 H22 model from the paired16 experiment
rather than the initially untrained H21 warm-start. Its already
established public-v1 checkpoint family makes full-episode termination
more representative. A new seed prefix avoids benchmark selection on
previous training/evaluation seeds.

```fish
cd ~/projects/sts2-ai
git switch perf/p2-h22-packed-collator-20261105
git pull --ff-only

set emu ~/projects/sts2-emulator
set rev (git -C $emu rev-parse HEAD)
set trained results/h22-packed-paired16-two-rounds-v1/models/joint-r0002.pt
set out results/p2-h22-closure-fullact-a0-v1

test -f $trained; or begin
    echo "Missing trained H22 checkpoint: $trained" >&2
    exit 1
end

# First preview the four cohorts and exact benchmark identity; no execution.
python tools/run_p2_actor_abba.py \
    --experiment h21-collator --ai-root (pwd) \
    --emulator-root $emu --emulator-revision $rev \
    --checkpoint $trained --macro-prior-weight 0 \
    --workers 15 --actor-device cuda --actor-deterministic-cuda \
    --h21-max-batch 4 --h21-fixed-batch-size 4 \
    --ascension 0 --map-profile generated \
    --horizon-lambda 0.4113950303216448 \
    --seed-count 16 --seed-prefix p2-h22-closure-a0-20261105-v1 \
    --simulations 16 --depth 8 --max-searches 2 \
    --max-decisions 4096 --require-full-act \
    --output-root $out

# Run the same command with --execute. It executes A1/B1/B2/A2
# sequentially and rejects any replay/work/censoring mismatch.
python -u tools/run_p2_actor_abba.py \
    --experiment h21-collator --ai-root (pwd) \
    --emulator-root $emu --emulator-revision $rev \
    --checkpoint $trained --macro-prior-weight 0 \
    --workers 15 --actor-device cuda --actor-deterministic-cuda \
    --h21-max-batch 4 --h21-fixed-batch-size 4 \
    --ascension 0 --map-profile generated \
    --horizon-lambda 0.4113950303216448 \
    --seed-count 16 --seed-prefix p2-h22-closure-a0-20261105-v1 \
    --simulations 16 --depth 8 --max-searches 2 \
    --max-decisions 4096 --require-full-act \
    --output-root $out --execute

# Verify the *strict* acceptance report and source checkpoint hash.
python tools/check_p2_h22_closure.py \
    --report $out/p2-h22-collator-abba-report.json \
    --checkpoint $trained \
    --output $out/p2-h22-closure.json
```

The benchmark is **4 arms × 16 independent seeds × 2 paired
executions = 128 completed Act attempts**. "Completed" means an
actual Act clear or defeat, not necessarily a boss clear. It requires
identical public actions/PUCT teacher traces and identical search
and real transition counts for each matched seed, no censored
episodes, actual PUCT work, all arms CUDA/deterministic/fixed-4,
and complete provenance including emulator binary digest.

The closure checker refuses to accept the prior four-seed/censored
microbenchmark as final. It verifies the independent seed cohort,
strict report flags, model hash, all four complete arms, actor
configuration and raw wall arithmetic. Under the recorded
**practical promotion rule**, packed is a candidate for default
when **both order pairs are faster** and combined cohort-wall
speedup is at least **1.10×**. This 10% threshold is a local P2
promotion decision, not a theoretical gain guarantee.

A valid full-Act comparison with a smaller speedup can still close
the P2 *investigation*: retain `reference` as default and
`packed` as opt-in, document the negative result, and choose the
long-training actor accordingly. If parity, completion or
provenance fails, P2.5 remains open and the raw arm profiles must
be retained for diagnosis.
