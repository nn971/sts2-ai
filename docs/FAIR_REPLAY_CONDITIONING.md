# Fair public-history replay via bounded rejection conditioning

**Status (2026-10-08): correctness/reference prototype, opt-in, with pinned
emulator integration smoke. Real-game scale self-play is still blocked by the
acceptance rate of long observed histories and by the need to validate the
native game seed prior and ruleset.**

The `sts2-ai` parent already knows how to `reset(seed)`, observe,
enumerate legal actions, step and release the pinned emulator. This
experiment conditions fresh, independently seeded runs on the same
*complete* sequence of player-visible observations and actions.

## Conditional-law argument

Fix a **declared experimental prior** (U): a uniform 128-bit integer
encoded as the string `fair-sampling:<32 lowercase hex digits>`.
The pinned prototype RNG separately hashes that seed into its game
streams. This is an explicitly versioned distribution over hypothetical
emulator runs, and **not** a claim about STS2 native seed generation.

Let (H(U,a_{<t})) be the complete player-facing observation/action
transcript generated by replaying a fixed public action sequence on
the emulator initialized by (U). For a genuine player's transcript
(h), rejection-sample iid (U_1,U_2,\ldots) from the experimental
prior and accept those with (H(U_i,a_{<t})=h). Because the emulator
is deterministic conditional on (U), for every compatible event (B),

\[
\Pr(U\in B\mid H=h)=
\frac{\Pr(U\in B,\ H=h)}{\Pr(H=h)}.
\]

Accepted seeds thus follow the exact conditional distribution for
the **specified artificial seed prior**. Neither the live run's seed
nor its exact fork is passed to the sampler. The matching test includes
every public observation, the entire legal-action menu, and the chosen action at every step.
Only accepted state handles survive the sampling call; all rejected
states are immediately released.

The PUCT adapter uses a **fresh accepted root per simulation** and
keeps its hidden state only inside that simulation, advancing the
emulator's deterministic transitions until terminal. This retains
correlations between later draws, enemy rolls and previous hidden
randomness. PUCT selection only reads public action labels/history and
aggregate statistics, so search never gets the sampled hidden seed.

## Existing components

- `emulator/rejection.py`: `FairHistoryRejectionSampler`,
  `HistoryConditioningExhausted`, and attempt/acceptance counters.
- `search/fair_replay.py`: `FairReplayPuctAdapter` with a keyed
  public-history transcript store and per-simulation state lifecycle.
- `search/puct.py`: optional begin/end hooks for valid continuation
  sampling while keeping simple toy stochastic adapters working.
- `tests/test_fair_replay.py`: fixed mathematical toy with hidden bit,
  public reveal, conditional posterior, deterministic reproducibility,
  handle accounting and correlated continuations.
- `tests/test_fair_replay_bridge.py`: real pinned JSONL emulator smoke
  on the publicly identical RunStart state from different live seeds.

## Minimal usage

```python
import random
from sts2_ai.emulator import (
    FAIR_POLICY_ID, InformationPolicy, JsonlEmulatorBackend,
)
from sts2_ai.emulator.chance import PublicHistoryStep
from sts2_ai.search.fair_replay import FairReplayPuctAdapter
from sts2_ai.search.puct import StochasticPuct

with JsonlEmulatorBackend() as backend:
    real = backend.reset("example-live-seed")
    try:
        observation = backend.observe(real, InformationPolicy(FAIR_POLICY_ID))
        legal = tuple(backend.legal_actions(real))
        # Only the fair observation/legal actions go into the adapter.
        model = FairReplayPuctAdapter(
            backend, goal="prototype-act1-clear-v1", max_candidates=128,
        )
        root = model.root([PublicHistoryStep(observation, None)], legal)
        report = StochasticPuct(model, seed=29, max_depth=128).search(
            root, simulations=16,
        )
        print(report)
    finally:
        backend.release_many([real])
```

Long full-game rollouts may be very expensive; this example illustrates
the interface and carries **no guarantee of useful search results**.

For decisions after RunStart, supply the *entire* public transcript:
every historical `PublicHistoryStep(observation, chosen_action, legal_actions)`, then
`PublicHistoryStep(current_observation, None, legal_actions)`. Merely supplying the
current screen drops historical conditioning and is invalid.

## Censoring and goal semantics

The adapter supports two explicit prototype objectives:

- `prototype-full-victory-v1`: terminal victory success, defeat failure.
- `prototype-act1-clear-v1`: observed entry into Act 2 success, terminal
  defeat in Act 1 failure; run victory also certifies an Act-1 clear.

The adapter records normalized HP at its **declared endpoint**.
Progress is intentionally left absent until an episode-specific
native Overgrowth floor/room normalization is verified. Search raises
on incomplete rollouts rather than inventing success/failure labels.

## Hard limits / next engineering gate

1. **Acceptance collapse.** A fully revealed generated map or unusual
   reward/deck/history may have tiny mass under random seed strings.
   Conditioning by rejecting complete hypothetical runs then becomes
   exponentially expensive. The default cap is 256 candidates *per
   PUCT simulation*, and the adapter raises
   `HistoryConditioningExhausted` instead of substituting a seed-fixed
   oracle fork or treating the run as a defeat.
2. **Seed prior and game parity.** Uniform 128-bit synthetic seed strings
   are a *prototype testing ensemble*. Native STS2 seed semantics and
   chance stream initialization require additional verification.
3. **Strict history equivalence.** The observation contains instance
   identifiers and other fine-grained visible fields. Exact matching
   can reject histories that have equivalent strategic information,
   further reducing acceptance; a coarser equivalence needs its own
   audited policy version.
4. **No current player-agent promotion.** This is a research adapter, not
   an enabled default agent. Existing heuristic and oracle-exact MCTS
   are unchanged. The next engineering step is an efficient, certified
   observation-conditional sampler for actual Overgrowth mechanics.

The worthwhile successor is **conditional resimulation of hidden
streams using verified distribution laws**, respecting shuffles without
replacement, correlated streams and information revealed by actions.
Use the exact rejection sampler as a numerical/semantic reference on
low-entropy histories to verify approximate posterior methods. Future
experiments should measure acceptance fraction vs floor/phase,
sampling wall time and simulator transitions before RL scale-up.
